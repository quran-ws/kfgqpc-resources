## تعريف / Definition

الميسر في غريب القرآن الكريم  
هي خدمة يقدمها مجمع الملك فهد لطباعة المصحف الشريف للمطورين والباحثين ودور النشر لاستخدامها في محتوى تطبيقاتهم (المكتبية ، والجوال ، والمتصفحات) وأبحاثهم، وهذا المحتوى موثوق به ومعتمد من قبل مجمع الملك فهد لطباعة المصحف الشريف، ويحتوي على بيانات الميسر في غريب القرآن الكريم برواية حفص.

## دليل الاستخدام / Usage guide

The database contains the following fields:  
1- id (int): Auto_increment Number  
2- page (int): Page Number  
3- sura_name (varchar): Sora Name in Arabic (Uthman Taha Naskh font)  
4- aya_no (int): Aya Number  
5- quranic_words (text): Text of the Quranic word in (UthmanicHafs font)  
6- explanation (text): Text of the Tafseer of the Quranic word in (Uthman Taha Naskh font)  
It includes two folders:  
1– It contains folder of MuyassarGhareeb fonts (Uthmanic Hafs font and Uthman Taha Naskh font).  
2- It contains files for developers (Excel, CSV, HTML5, SQL, XML, JSON and PDF).
