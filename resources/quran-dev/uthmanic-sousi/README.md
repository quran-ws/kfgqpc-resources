رواية السوسي عن أبي عَمْرِو البَصْريّ: وهي من الروايات التي يستفيد منها المتخصصون في القراءات من طلبة العلم وغيرهم.

## دليل الاستخدام / Usage guide

The database contains the following fields:  
1- id (int): Auto_increment Number  
2- jozz (int): Jozz Number  
3- page (varchar): Page Number (There are some Ayat in two pages we separated with – symbol)  
4- sura_no (int): Sura Number  
5- sura_name_en (varchar): Sura Name in English  
6- sura_name_ar (varchar): Sura Name in Arabic (kfgqpc_sousi_uthmanic_script ttf font file)  
7- aya_no (int): Aya Number  
8- line_start (int): Start Line of Aya  
9- line_end (int): End Line of Aya  
10- aya_text (text): Text of the Aya in kfgqpc_sousi_uthmanic_script ttf font file (Adding Aya mark as Symbol to all files in UthmanicSousi_v2-0 data folder except Excel file to display Aya mark properly)  
It includes two folders:  
1- It contains font file and whole Qur’an data in MS document file.  
2- It contains files for developers (Excel, CSV, HTML5, SQL, XML, JSON and PDF).
